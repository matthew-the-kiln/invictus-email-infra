# Invictus Email Infrastructure

Scrolltelling page for the Invictus email infrastructure plan (DNS move to Cloudflare, 16 domain redirects, Google Workspace records).

Single static file: `index.html`. GSAP and ScrollTrigger load from cdnjs.

Preview locally: `python3 -m http.server 8000`, then open http://localhost:8000

Hosted with GitHub Pages from the `main` branch root.
